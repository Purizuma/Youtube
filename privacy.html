Privacy Policy

Last updated: October 2, 2026

Atom to Alloy Uploader ("the app") is a personal tool used by its developer to upload videos to the developer's own YouTube channel.

What the app accesses

With the owner's permission, the app uses Google OAuth to access the owner's YouTube account. It requests two permissions: uploading videos (youtube.upload) and viewing the account's YouTube channel information (youtube.readonly), which is used only to show which channel is connected.

What it stores

The app keeps an OAuth login token on the owner's own computer so that it does not need to ask for a login every time. It does not collect, store, or process any other personal data.

Sharing

The app does not sell, share, transfer, or disclose any user data to third parties. It runs only on the owner's computer and has no servers or databases of its own. Its use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can remove the app's access at any time at myaccount.google.com/permissions and by deleting the local token file.

Contact

Questions can be sent through GitHub Issues.
